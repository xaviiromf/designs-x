# Series two: art direction

Fifteen designs added to the seven from the Arcade series, built in [designs-x-personal-taste](https://github.com/xaviiromf/designs-x-personal-taste) and ported here unchanged, in three batches of five. Section split: portfolio 4, crud 2, nav 2, faq 2, contact 2, testimonials 1, process 1, footer 1.

The art direction was done before any design was built: one concrete fictional subject each (none repeating the first seven), one chosen dark ground each (spread around the colour wheel, none repeating), five to seven hues with one job each, and an exclusive matrix of effects per design (signature, pointer, scroll, load, button hover and press, text links, fields, dialog, success). No effect repeats the ledger or another design in the series. `research/effects-ledger.md` records what was actually built.

## Effects matrix as briefed

One line per design: pointer / scroll / load / button hover and press / text link / field / dialog / success.

- `portfolio-isometric-artist`: picked tower separates into floors / crane sets slabs with scroll / lot tiles laid diagonally, headline lines land as slabs / editor zoom grid, nudge / stair underline / ruler with a marker at the text's width / stands up from an isometric tile / topping out a small tower.
- `crud-memory-card`: block icons play two frames / block gauge docks to the top / blocks read in order / sticker peel, pressed flat / two-frame glyph / write-protect tab slides shut when valid / the card turns over / block-by-block write with the access light.
- `nav-game-museum`: marker walks the shortest tile path / you-are-here minimap strip / room swatches collapse to markers / ticket stub tears, punched / pin drops and route dots / a doorway opens in the field's wall / swing gate / date stamp inked in two frames.
- `faq-handheld-clinic`: pressing the LCD leaves a dithered pool / screen follows the fault group, contrast wheel notches / screen powers through dither levels / membrane rings, bottomed out / dither-density underline / contrast steps up through a dither frame / panel through dither levels / four-shade bars and a tick.
- `contact-hackerspace`: ping rings from the pointer / range steps 2 km, 500 m, 100 m / first ping reveals the chart / echo rectangles, contact / Morse underline / noise settles to a flat line when valid / clock wipe / the visitor's blip joins the chart.
- `portfolio-security-researcher`: orthogonal trace / redaction lifts as write-ups are disclosed / the trace boxes the primary button / packets split, sent / endpoints on the underline / double wall, breach / three bands reassemble from alternate sides / three-way handshake.
- `crud-cartridge-stall`: price tag drops on a string / tally marks stamped by scroll / the stall's lamps come on in two zones / starburst sticker, till flag / two chalk lines / string knots through the tag's hole, live typed reading / hung on a peg / chalked up with a new tally mark.
- `testimonials-capsule-club`: crank with four detents / capsule halves part as items pass / capsules stock the dome row by row / coin drops into the slot, return flap / seam opens / lid lifts / tumbles in a quarter turn at a time / the visitor's capsule drops with a slip.
- `process-convoy-night`: a wing breaks formation / one jump per step boundary / dropping out of a jump / thrust plume, burn / underline streaks past the text / docking clamps / airlock cycles / stars form the callsign's initials.
- `footer-cartridge-publisher`: breath blows the dust along the pointer's direction / dust settles into the name / column labels stuck on / cartridge lifts on its contacts, seated / specks fly off / shell notch / pulled out of its sleeve / end label written, one gust.
- `portfolio-chiptune-composer`: edit cursor and meter kick / order list, scroll steps the playhead / pattern loads in four blocks / pulse-width edge, inverted phase / square-wave vibrato underline / current-row band / four channel strips / four-note fanfare.
- `portfolio-disk-archivist`: read head jumps to the pointer's row / scroll drives the consolidation / outcomes develop class by class / shutter slides, pushed into the drive / head travels the underline and parks / checksum pips / three magnifications / parity pip settles.
- `nav-pirate-radio`: needle follows in detents and locks / scrolling tunes between stations / band scan / tuning eye closes, locked / broken underline closes / antenna telescopes / frame switches on clockwise / slip dropped on a spike.
- `faq-hint-hotline`: key preview of row and column tones / cord pays out, display follows the reading / handset lifts off the hook / hook switches pop up, hung up / double ring / plug seats in a jack / opens from a line / the keypad dials the call-back number.
- `contact-privacy-helpdesk`: a lane rains harder / scroll and typing are the rain's only clock / twelve ticks of rain / shackle closes, key turns / underline closes into a box / ciphertext strip grows with the message / deadbolt thrown / rain locks into the message's fingerprint.
