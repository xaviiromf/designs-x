      House rules for the card

      1. One save per regular per game. If Ania starts Kiln Knight again, update her save instead of adding a second one. The card will refuse a duplicate.
      2. When the card is full, the oldest save goes first. Sort by last played, and ask at the bar before you delete a save someone used in the last 90 days.
      3. A finished game keeps its save for a month, so the regular can show their friends the ending. Then it can go.

      Where these saves live

      These saves are kept in this browser tab only. Closing the tab clears them, and nothing is sent anywhere.
